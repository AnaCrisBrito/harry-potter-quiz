# Harry Potter Quiz

Um quiz interativo desenvolvido em Python, inspirado no universo de Harry Potter.

O projeto tem como objetivo praticar conceitos de lógica de programação e aprofundar os conhecimentos na linguagem Python por meio do desenvolvimento de um jogo de perguntas e respostas.

## Funcionalidades

- Perguntas sobre o universo de Harry Potter.
- Quatro alternativas por pergunta.
- Quatro níveis de dificuldade.
- Pontuação de acordo com a dificuldade.
- Feedback imediato sobre as respostas.
- Resultado final com desempenho do jogador.

## Tecnologias

- Python
